# 喵喵站桩英雄

原创双猫插画小游戏，支持手机横屏与电脑浏览器，无需注册。

## 玩法

- 金渐层「奶糖」偏进攻，蓝猫「蓝莓」拥有首击护盾。
- 按住角色向下拖动调整角度；手指离角色越远，力度越大，松手投掷。
- 圆柱力度条从绿色过渡到蓝色、红色，弧形虚线预览抛物线。
- 共 10 关，加入风力与高低木桩；通关后从 6 款数字手办中随机出现 3 款，选择 1 款结束冒险。
- 闯关进度与奖励保存在当前浏览器。

## 本地运行

在项目目录运行 `python3 -m http.server 8080`，浏览器打开 `http://localhost:8080`。

## Render 部署

创建 Static Site，连接本仓库；Build Command 填 `true`，Publish Directory 填 `.`。

本项目为纯静态 HTML/CSS/JavaScript，不需要后端、数据库或环境变量。
